# ADR-0008: Secure playback: HMAC playback tokens + per-request presigned redirects (not DRM)

- Status: Accepted · Date: 2026-10-22

## Context
Private bucket; playlists AND segments must be authorized; revocation needed; no media through gateway.

## Options
(a) Public CDN URLs; (b) presigned URLs embedded in playlists; (c) tokenized playback paths that 302 to short-lived presigned object URLs; (d) DRM (paid/complex).

## Decision
(c). `POST /api/v1/playback/sessions` checks publication/takedown/ownership and returns a 15-min HMAC token bound to session/asset/version. `GET /api/v1/playback/stream/{token}/master.m3u8` and variant playlists are generated by the playback service (small text); every segment URI points back to `/stream/{token}/...`, which validates token + revocation (Valkey with DB fallback) and answers `302` to a 60-s presigned GET. Revoking a title or session stops all further segments within one segment duration. Responses `Cache-Control: private, no-store`.

**Storage CORS.** The browser fetches segments by following the playback service's `302` from the gateway origin to the storage origin. Per the Fetch specification this cross-origin redirect marks the request origin as *tainted*, so storage receives `Origin: null`. The media bucket therefore answers CORS with `Access-Control-Allow-Origin: *` (no credentials). This does not weaken access control: CORS never protected unauthenticated GETs; the capability is the presigned signature, valid for 60 s and only obtainable from an authorized, non-revoked playback session. Found during browser verification (2026-10-22) — the Python e2e client does not enforce CORS, which is why Playwright now covers playback.

## Rationale
Authorizes every object fetch, works with R2/MinIO, no edge workers needed.

## Consequences
An already-issued 60-s presigned URL can be replayed until expiry; this is access control, **not DRM** — screen capture/downloading by an authorized viewer is not prevented.

## Revisit Trigger
Need for offline/DRM or CDN edge caching of segments.
